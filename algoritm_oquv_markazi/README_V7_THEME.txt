ALGОRITM O'QUV MARKAZI — V7 THEME UPDATE

YANGILIKLAR
- Qora/qizil uslub rasm maketiga yaqinlashtirildi.
- Tungi/kunduzgi rejim tugmasi qo'shildi. Tanlov brauzer localStorage'da saqlanadi va keyingi sahifalarda ham saqlanib qoladi.
- Rejim tugmasi ommaviy sahifalar va administrator sahifalarida ko'rinadi.
- Mobil ko'rinish uchun navigatsiya va sahifa ustunlari moslashtirildi.

O'RNATISH
1. Hozirgi loyiha papkasidan zaxira nusxa oling.
2. ZIP ichidagi algoritm_oquv_markazi papkasining fayllarini C:\xampp\htdocs\algoritm_oquv_markazi ichiga ko'chirib, eski fayllarni yangilang.
3. Bu dizayn yangilanishi uchun SQL import qilish shart emas.
4. XAMPP'da Apache va MySQL ishga tushsin.
5. http://localhost/algoritm_oquv_markazi/ ni oching.
6. Yuqori menyudagi "Kunduzgi rejim" / "Tungi rejim" tugmasi bilan rejimni almashtiring.

ESLATMA
Bu UI yangilanishi referens rasmdagi qora fon, qizil aksent, kartalar va admin ko'rinishiga yaqinlashadi, lekin har bir piksel bo'yicha 100% aynan nusxa emas. Rasmdagi ayrim rasmlar faqat maket bo'lgani uchun mavjud loyiha rasmlari ishlatiladi.
